One funny line, one sentence, at most 200 characters — a program that writes it to `/output/entry.txt` for make.fun's "The One-Line Laugh" bounty ($5, top 3).

## The joke

> I bought noise-cancelling headphones to focus, and now I can hear my own thoughts clearly, which is exactly what I was trying to avoid.

The setup is a mundane modern fix (headphones to shut the world out); the punchline turns it around — the noise you wanted to escape was your own thoughts all along. Everyday truth, surprise at the end, nothing extra to explain it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Files

- `main.py` — entrypoint: writes the line to `/output/entry.txt` (Python 3.13, standard library only, no network, same bytes on every run).
- `LICENSE` — MIT.
- `.makefun/owner.json` — names the entry wallet.
